## 4. Что из этого следовало для гл.36–40 и эпилога (исходные ошибки v2)

- гл.36: у Ио «уже лежала одна катушка», борт — «второй случай»; Лира кладёт «вторую катушку рядом с первой»; «Теперь это два места, рудник и борт… не вынесу, пока не будет третьего». По хронологии: борт — **шестое место и четвёртая катушка**; три случая уже докладывались залу.
- гл.37: Ротт «У Ио, кажется, уже не одна катушка» — Ротт сам слушал три катушки (гл.16, 21).
- гл.39: Ио «после второй катушки» — правильно «после катушки с борта» (четвёртой).
- эпилог: «что Ио сняла с рудника и с борта» — Ио снимала с рудника, сада, двора и борта.
