# NAEON — Glossary (Aexion / Player-Facing)

**Version:** 0.1  
**Use:** UI tooltips, codex, onboarding  
**Language:** EN baseline; RU keys may mirror in localization later

| Term | Short definition |
|------|------------------|
| **Aexion** | The wider star-setting of NAEON’s systems and routes |
| **NAEXOS** | Pre-Schism / ideal network and social-technical project; also platform bridge fantasy |
| **NAEON** | The game / the living conflict era after the Schism |
| **Schism** | Split over rewrite limits and control of the Lattice |
| **Lattice** | Transgalactic communication and coordination network |
| **ARK** | Planet hosting NEX and the bulk of hibernating humanity |
| **NEX** | Protected city / vault complex of the sleepers |
| **Sleepers** | Baseline humans in long hibernation |
| **Cybernex** | Caretaker faction: limits, Firewall, Contribution, harmony-tech |
| **gROT** | Swarm faction: biomass, Hacking, Infection, ROT |
| **ROT** | Immortal singular leader of gROT |
| **Noo-people** | Remaining edited humans among Cybernex |
| **Contribution** | Cybernex prosperity score from delivery / shared work |
| **Biomass** | gROT growth score from conversion / harvest |
| **Infection** | Stacking pressure effect (max **5** pips); cleansable |
| **Nex-Firewall / Firewall** | Cybernex answer to Hacking; cleanse + short protect |
| **Hacking / Infect Link** | gROT channel pressure tool |
| **Dynamic Ownership** | Claimable objects change look and services by faction |
| **Contested** | Ownership in active dispute |
| **War Score** | Soft, capped Arena→world influence (not free planet flip) |
| **Knowledge** | Soft informational mastery — never raw combat power |
| **Form** | Player/NPC body presentation within budget |
| **Vein** | gROT metaphor for continuous conversion growth |
| **Wake** | Cybernex metaphor for eventual sleeper return |
