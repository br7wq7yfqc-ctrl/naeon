# NAEON — Faction Slang & Voice Markers

**Version:** 0.1  
**Use:** NPC barks, player emotes, VO direction, UI microcopy flavour  
**Not** a power system

---

## Cybernex markers

| Marker | Meaning / use |
|--------|----------------|
| **Lattice** | Network, order, shared plan |
| **Wake / waking** | Hope of sleeper return; readiness |
| **Clean** | Free of Infection; also moral clarity |
| **Hold the ring** | Defend NEX/ARK perimeter |
| **Contribution** | Work that feeds the shared good |
| **Bleed** | The First Bleed / infection disaster (spoken carefully) |
| **Soft no** | Refusal wrapped in protocol |

Tone: precise, duty-weighted, occasional dry tech humour.
