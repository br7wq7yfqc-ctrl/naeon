## Core Design Decisions (locked)

1. **Factions** — Cybernex (RBE, harmony, animal-robots + noohumans) vs gROT (biomass, assimilation, ROT).
2. **The Schism** — infection via transgalactic network, hibernation of humanity, genetic editing trade-offs.
3. **Asymmetric abilities** — Hacking/Infection (gROT) vs Nex-Firewall (Cybernex); soft and counterable.
4. **Dynamic Ownership Transformation** — visual + gameplay change based on faction control.
5. **Knowledge System** — optional, soft combat benefits only, generated via aiNEX.
6. **Economy** — Contribution (Cybernex) / Biomass Rank (gROT); no hard P2W.
7. **Assets** — outside git, dual-theme variants preferred over new paid generations.
