# NAEON Design Pillars (Locked)

1. Asymmetric but fair factions
2. No pay-to-win
3. Soft Knowledge only
4. Dynamic Ownership matters (visual + gameplay)
5. Counterplay first
6. Economical creation (Tripo-first, dual-theme)
7. Multi-layer one universe (soft capped influence)
8. Low-end respect
9. Platform bridge (NAEXOS.ONLINE / aiNEX)
10. Long war, not instant resolution

If a feature conflicts with a pillar, change the feature.
