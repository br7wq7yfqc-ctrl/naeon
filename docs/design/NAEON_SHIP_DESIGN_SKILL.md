# NAEON Ship Design

Load **`naeon-asset-design` first.** This file is hull-only.

## Hull

- Capitals enter atmosphere: not bricks, not space-cities.
- Cybernex: flatter, bird-like, planar plates.
- gROT: asymmetric cyber-biomass 20–35% on industrial frame. Not a brick.
- Mothership: capitals **dock externally**. They do not fly into hangars. CX hex superstructure. GR rhomboid bio-industrial.

## Engines

Proud on **flat transom**. Exhaust into **open space**. No niche. Main + RCS.
