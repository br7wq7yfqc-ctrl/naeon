# NAEON — Alliance Hierarchy, Permissions & Social Rules

**Version:** 0.2  
**Status:** Design authority

---

## 1. Purpose

Alliances coordinate Ownership, logistics, and constructor quests. Hierarchy without harassment tools or P2W claim advantages.

---

## 2. Ranks (0–4)

| Rank | Cybernex / gROT name | Powers |
|------|----------------------|--------|
| 0 | Applicant / Drone | Join requests |
| 1 | Member / Pack | Text chat; opt-in pool deposit |
| 2 | Officer / Fang | Constructor (limited templates), invite |
| 3 | Steward / Spine | Structure access lists, pool policy, promote officers |
| 4 | Leader / Voice | Diplomacy, disband/transfer, rank edit |

Names cosmetic; powers mirrored for fairness.

---

## 3. Object permissions

Leaders set: dock/enter, storage deposit/withdraw, operate defenses, claim/abandon, constructor targeting.

Default: members dock + deposit; Officer+ for withdraw and defenses.

---

## 4. Shared pools

Contribution (Cybernex-leaning) and Biomass (gROT-leaning) ledgers with daily transfer caps. No conversion into personal combat power.

---

## 5. Chat and voice

Text for members+. Voice by subscription or achievement (thresholds TBD). Rank 3–4 moderation with logging; Community Guidelines apply.

---

## 6. Constructor limits

Templated only. Daily reward budget from alliance pool + server caps. No personal-harassment objectives. War templates vs enemy Ownership allowed.

---

## 7. Leadership and disband

Transferable rank 4. Inactivity auto-transfer to prevent deadlocked map holds. Disband → objects enter Neutral or Contested decay per Ownership rules.
