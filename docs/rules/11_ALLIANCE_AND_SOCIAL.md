# 11 — Alliance & Social Systems

**Version:** 0.1

## Hierarchy
- Leader / Council / Officers / Members / Recruits
- Rights: claim structures, manage resources, create alliance quests, invite, kick, set taxes / contribution goals

## Shared Resources
- Alliance Contribution / Biomass pool
- Shared blueprints and stockpiles
- Access control per structure

## Communication
- Text chat always available
- Voice channels: subscription or high achievement gate
- Alliance hubs with bulletin and objective board

## Alliance Quests
Created via constructor with validation (sinks, time gates, objective limits) to prevent abuse.
