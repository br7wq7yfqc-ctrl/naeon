# 13 — MOBA / Arena Soft Influence

**Version:** 0.1

Victories in Aexion Clash / Arena grant temporary War Score / claim_strength bonuses toward map objects.

Rules:
- Soft only — never permanent lock without actual presence on the map.
- Hard seasonal / monthly caps.
- Cannot override a well-defended major structure alone.
- Designed to create meaningful but non-destructive linkage between competitive and MMO layers.
