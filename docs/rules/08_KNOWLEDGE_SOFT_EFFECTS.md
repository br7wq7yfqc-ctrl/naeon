# 08 — Knowledge Soft Effects

Knowledge never grants raw damage, HP or hard power.

| Subject | Soft Benefit |
|---------|--------------|
| Cybernetics | Clearer Infection UI, earlier hack warning |
| Programming | Limited enemy cooldown tooltips |
| Logistics | Better cargo estimates |
| Ecology | Resource node highlight |
| History | Extra lore & dialogue |
| Mathematics | Better crafting previews |
| Physics | Minor trajectory UI |
| Biology | Faster biomass hazard ID |
| Languages | Additional dialogue variants |
